# ルーバーライン デモサイト

初回打ち合わせ用のデモサイトです。サーバー不要で、`index.html` をダブルクリックするだけでブラウザで開けます。

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ（ファーストビュー／コンセプト／製品概要／導入事例概要／会社案内概要／お問い合わせCTA） |
| `products.html` | 製品紹介（可動ルーバー自動制御システムの特長・仕組み・機能・ラインナップ） |
| `cases.html` | 導入事例一覧（用途で絞り込み可） |
| `cases/*.html` | 導入事例の詳細（5物件） |
| `company.html` | 会社案内（事業内容・OEMの関係・会社概要） |
| `contact.html` | お問い合わせ（デモ用フォーム。送信してもメールは飛びません） |

## 仮の情報・仮画像（本番前に差し替え）

- 会社案内・フッターの **住所・電話番号** は仮です（`build.py` の先頭 `TEL` / `POSTAL` / `ADDRESS` で一括変更）
- `assets/img/company-building.svg` … 本社外観の仮画像
- `assets/img/cabinet.svg` … 制御盤の仮画像
- `assets/img/panel-auto.svg` / `panel-manual.svg` … タッチパネル画面の仮画像
- `assets/img/system-diagram.svg` … システム構成図（内容は資料ベース、見た目は仮）
- お問い合わせフォームの送信先（本番ではフォームサービス等を設定）

## 文章や事例を直したいとき

共通ヘッダー・フッターや事例データは `build.py` にまとめてあります。
`build.py` を編集して、このフォルダで次を実行すると全HTMLが再生成されます。

```
python build.py
```

HTMLファイルを直接編集しても構いませんが、その場合は `build.py` を再実行すると上書きされるのでご注意ください。

## 素材の出典

- ロゴ・メインビジュアル・物件写真：`..\ロゴ`、`..\画像`、`..\物件` のファイルをリサイズして `assets/img` にコピー
